Guide Editor help

Create and save

  1. Choose File → New or open a UTF-8 text/Lua file (up to 12 MiB).
  2. Select a step and instruction. Edits apply as you type; new instructions need Add instruction. Use Undo/Redo to reverse edits.
  3. Use Check source. Click a problem to find its line.
  4. Save file downloads the whole file; Save guide text exports one guide.

Edit advanced instructions in Source. On small screens, Steps opens the outline.

The browser keeps one draft, restored through File. Download backups before switching documents; browser storage can be cleared.

Guide properties

Use a unique name under RXPGuides Custom Guides, or choose Save as new guide. Imported identities stay unchanged.

Server, purpose, zone, description and requirements are comments, not gameplay restrictions.

Use in WoW

  1. Export Save guide text.
  2. In RXPGuides, choose Import → Website guide source, paste and save. Update the addon if this option is missing.
  3. Reload when ready, then select Type → Custom guides in the library.

Import supports basic instructions, not executable Lua, macros or includes. Replacements require confirmation. External Lua dependencies block guide export; use Save file to retain the original.

Back up SavedVariables and test on a disposable character. Names and step order can affect saved progress. Source checks do not verify gameplay.

Instructions and maps

Use one step per walking destination. Travel objectives default to a 15-yard arrival radius. Notes, navigation-only markers, target/mob helpers and item buttons need a separate completion objective, such as a quest or Manual objective (+).

  • Choose a continent and zone. Drag or use arrow keys to pan; wheel or +/− to zoom.
  • Click terrain or enter X/Y, then Add waypoint or Replace coordinates. Drag waypoints to move them; Escape cancels.
  • Filter by layer, faction, profession or event. Shared locations stay visible with either faction off. Location details offers IDs and instruction actions.

Map filters last for this session. Existing waypoint radii are preserved.

Locations use an AzerothCore snapshot, not live NPC positions or guaranteed quest availability. Events are not a live calendar; route lines show instruction order, not safe paths.

Interiors are view-only, with instance-wide entity lists where available. They have no mapped floors or clickable coordinates. Unsupported waypoints stay in Source.

Lookup

Wowhead WotLK IDs and links load here. Partial titles open a new tab; paste a result link back, then choose Use in instruction. Object IDs require Source editing.

Verify server availability. Quest objective indices come from the in-game quest log, not database slots or tooltip order.

Privacy

  • Guides stay in your browser. Lookups send IDs/types or search text to Wowhead; no Wowhead scripts or trackers are embedded.
  • Cloudflare Web Analytics measures visits, referring pages, countries and performance without analytics cookies. We do not send guide text, drafts or form values to analytics.
  • Imported Lua is read as text, never executed here. Review imported code before using it in WoW.
