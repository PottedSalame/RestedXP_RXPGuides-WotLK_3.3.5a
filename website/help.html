Guide Editor help

Create and save

  1. Use File → New or Open a UTF-8 text/Lua file (up to 12 MiB). Select a guide, step and instruction.
  2. Edit in Write, Map or Source. Existing instructions update as you type; new ones require Add instruction. Undo/Redo reverses edits.
  3. Use Check source; click a problem to find its line.
  4. Save file downloads the entire document. Save guide text exports the selected guide.

Source shows the entire file, including advanced instructions. On small screens, use Steps to open the outline.

One draft is saved in this browser. Restore it through File. Browser storage can be cleared or unavailable; download a backup before switching documents.

Guide properties

Set the name, group and version. Server/realm, purpose, zone, description and requirements are source comments—not gameplay restrictions. The editor suggests a custom-guides contribution path.

Use a distinct name under RXPGuides Custom Guides. Save as new guide creates an independent copy; imports are not automatically renamed or converted.

Use in WoW

  1. Export Save guide text.
  2. In the addon's Import tab, choose Website guide source, paste the text and confirm saving. Exported Guide.lua also works.
  3. Reload when ready, then select Type → Custom guides in the library.

This import accepts basic editor instructions, not executable Lua, macros or includes. Replacing a saved import requires confirmation.

Companion addon — alternative for older builds
  1. Choose a folder suffix in Export and download both the .toc and Guide.lua.
  2. Close WoW. Put both files in the displayed Interface/AddOns/RXPGuides_Custom_…/ folder. The .toc filename must match the folder name.
  3. Restart WoW, enable the companion alongside RXPGuides and select the guide.

Test on a disposable character and back up SavedVariables. Check travel, quest IDs, counters, rewards and reload restoration. Editing names or step order can affect saved progress.

Instructions and maps

For walking routes, use one step per destination. New travel objectives use a 15-yard arrival radius. Navigation-only waypoints, notes, target/mob helpers and item buttons need another completion objective; use a quest, collection or Manual objective (+).

  • Choose a continent and zone. Drag to pan; use the wheel or +/− to zoom. Arrow keys pan a focused map.
  • Click terrain, then Add waypoint or Replace coordinates. Drag a waypoint to move it; Escape cancels. Numeric X/Y entry also works.
  • Use Layers, professions and events to filter locations. Location details offers entity IDs and instruction actions.

Existing waypoint radii are preserved. Map view and filters last for this session only.

Markers are AzerothCore snapshot spawn/home locations, not live positions or guaranteed quest availability. Event filters are not a server calendar. Lines show instruction order, not safe paths.

Dungeon and underground images are view-only, not mapped floors. Use their instance-wide entity lists where available; clicking interior images cannot create coordinates. Unsupported map forms remain source-only.

Lookup

Enter an ID or link for Wowhead WotLK details. Partial titles open search results in a new tab; paste a result link back. Use in instruction applies the selected result.

Verify availability on your server. Quest objective indices come from the client quest log, not database slots or tooltip order. Object lookups require source editing.

Privacy and limits

  • Guides and drafts stay local. Lookups send the requested ID/type to Wowhead; title searches send the search text. No Wowhead scripts or trackers are embedded.
  • Imported Lua is read as text, never executed by the website. Original-file downloads preserve comments and surrounding code; unchanged imports retain their bytes.
  • External Lua dependencies or ]] inside a guide block companion export, not raw saving. Review advanced source before installing it.
  • Checks do not simulate conditions or certify gameplay. Missing maps or lookup data do not prevent manual editing.
